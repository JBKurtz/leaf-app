# Leaf — marketing site

The public home for **Leaf**, a location-first plant field guide for iOS. Static site served via GitHub Pages.

- `index.html` — home page (for people new to Leaf)
- `beta.html` — beta program page (closed beta now; open-beta registration form)
- `style.css` — shared Verdant design system (dark botanical, lime accent)
- `leaf-icon.png` — app mark / favicon

Plain static HTML/CSS with a touch of vanilla JS for scroll reveals. No build step, no dependencies.

To change the open-beta signup, edit the `forms.gle` link in `index.html` and `beta.html`.
